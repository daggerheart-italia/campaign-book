# Mobile UI improvements for campaign map

Plan file: `.kilo/plans/1794136091749-map-mobile-ui.md`

## Context

`resources/views/public/partials/map.blade.php` renders the interactive campaign map (Alpine `publicImageMap`). Desktop UX is good; mobile is poor: cramped toolbar, small touch targets, centered modal, weak affordances. Goal: improve mobile ergonomics without changing desktop layout or backend data. Scope confirmed: implement all six items below.

## Decisions

- Breakpoint for "mobile" = below `sm` (640px), matching Tailwind default.
- Bottom sheet only on mobile; centered modal on `sm+`.
- All changes confined to the Blade partial + Alpine component; no new components, no backend changes.
- Preserve existing desktop classes exactly; add responsive variants (`sm:`) rather than replacing.

## Tasks (ordered)

1. **Viewport height** — change `h-[70vh] min-h-80` to `h-[60vh] min-h-[420px] sm:h-[70vh] sm:min-h-80` (line ~51).

2. **Toolbar stacking** — outer toolbar div (line ~14): add `flex-col sm:flex-row` so labels toggle and zoom group stack on mobile. Zoom buttons: `min-h-11 min-w-11` (currently `min-w-8 ... py-1.5`). Labels toggle: `min-h-11`.

3. **Pin details bottom sheet** — wrap the details modal (lines 96-112). On mobile: `fixed inset-x-0 bottom-0 z-50` sheet with `rounded-t-2xl`, slide-up transition, max height `max-h-[70vh] overflow-y-auto`. On `sm+`: keep centered `sm:inset-0 sm:flex sm:items-center sm:justify-center` with `sm:max-w-md sm:rounded-2xl`. Add a drag handle bar at top. Backdrop unchanged.

4. **Pin list tap targets** — buttons (line 83): add `min-h-11`. Grid stays `grid-cols-1 sm:grid-cols-2 md:grid-cols-3`.

5. **Instructions collapse** — line 38-40 hint: shorten to `Trascina • Pizzica per zoom • Tocca un pin` on mobile via `hidden sm:block` for long version and `sm:hidden` for short version, or single responsive text.

6. **Floating reset button** — add a button positioned `absolute bottom-3 right-3 z-20` over the map viewport (inside the glass-panel, relative container line 42) calling `resetZoom()` + recenter; visible only when `zoomLevel !== 100` (`x-show`). Style: `btn-secondary !p-2 rounded-full shadow-lg`.

7. **Pinch feedback** — in `setZoomAt`, the canvas already resizes; add a subtle `transition-transform duration-75`? Skip — risk of jank. Instead ensure `will-change: transform` not needed. Mark as optional; implement only if time. (Decision: skip to avoid jank; rely on existing resize.)

## Files touched

- `resources/views/public/partials/map.blade.php` only.

## Edge cases

- Bottom sheet must not block map interaction when closed (`x-cloak` + `x-show` already).
- Floating reset button must not intercept pin clicks (position bottom-right, away from pins; `pointer-events` fine).
- Touch targets ≥44px (11 Tailwind units) for accessibility.

## Validation

- Manual: 360px viewport, pinch zoom, pan, pin tap, details open/close, map switch, reset button.
- `vendor/bin/sail npm run build` if assets change (none expected — Tailwind JIT handles classes).
- `vendor/bin/sail bin pint --dirty --format agent` (Blade not PHP; pint skips, but run anyway).

## Out of scope

- Backend/data changes, new components, JS gesture library, accessibility audit beyond touch targets.
